Conditionals Reference Guide

Type 0: General Truths & Scientific Facts

Used for things that are always true, scientific laws, habits, or general rules.

IF / WHEN + Present Simple, ... Present Simple
  • If you heat ice, it melts.
  • When it rains, the grass gets wet.
  • Plants die if they don't get water.
Type 1: Real & Possible Future Events

Used for real possibilities or likely results in the present or future.

IF + Present Simple, ... WILL + Base Verb
  • If it rains tomorrow, we will stay inside.
  • She will pass the test if she studies hard.
  • Unless you hurry, you will miss the bus. (Unless = If not)

Punctuation & Structure Tips

  • Comma Rule: If the "If clause" comes first, use a comma!
    e.g., "If it rains, we will cancel." VS "We will cancel if it rains." (No comma)
  • Never put "WILL" inside the IF-clause:
    If it will rain, we will stay... ❌
    If it rains, we will stay... ✅
